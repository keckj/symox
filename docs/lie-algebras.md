# Lie algebras and finite root systems

[README](../README.md) · [Combinatorics](combinatorics.md)

`symox.liealgebras` provides `CartanType`, the single export of the corresponding
SymPy 1.14 package. The implementation covers finite Cartan root data; this
name-presence count does not imply all Lie algebra submodules or representation
theory are implemented. See the [reference interfaces](https://docs.sympy.org/latest/modules/liealgebras/index.html).

```python
from symox import Matrix
from symox.liealgebras import CartanType

c = CartanType('A3')
assert c.rank() == 3
assert c.cartan_matrix() == Matrix([[2, -1, 0], [-1, 2, -1], [0, -1, 2]])
assert c.roots() == 12
assert c.basis() == 15
assert len(CartanType('E8').positive_roots()) == 120
```

String inputs such as `'E6'` and pairs such as `['B', 3]` construct finite types.
An existing Cartan type is accepted unchanged. Supported ranks are `A_n` for
`n >= 1`, `B_n` and `C_n` for `n >= 2`, `D_n` for `n >= 3`, `E_6/E_7/E_8`,
`F_4` and `G_2`. Invalid or unsupported specifications raise an error. Affine,
indefinite and reducible/product Cartan types are not implemented.

Methods supply rank, ambient coordinate dimension, simple roots, all positive
roots, the highest root, root count, Cartan matrix, the dimension of the Lie
algebra (`basis()`), family labels and text Dynkin diagrams. The methods
`simple_root(i)` use one-based indices; `basic_root(i, j)` uses zero-based
ambient indices. `dimension()` is the dimension of the chosen root embedding,
not the dimension returned by `basis()`.

Roots are generated by closing the simple roots under their exact reflections
in integer simple-root coordinates. Positive roots have nonnegative simple-root
coefficients. Ambient coordinates remain exact, including half-integral
exceptional roots. Returned lists/dictionaries are independent copies; the
cached reflection data are immutable. No floating-point root discovery or
SymPy runtime calls are used. Scalar outputs and Cartan matrices use native
Symox arithmetic.

The conventions use `A[i,j] = 2*(alpha_i, alpha_j)/(alpha_j, alpha_j)`.
Classical root dictionaries follow the reference ordering. Exceptional roots
use a deterministic height ordering. Their list numbering and some embeddings
can differ from SymPy 1.14. In particular, `F4` uses simple roots consistent with
its Cartan matrix, and exceptional positive roots are generated independently
rather than copying the reference's enumerated lists. `basis()` consistently
returns `rank + number_of_roots`, including `dim(A3) = 15` and `dim(D4) = 28`.
These mathematical invariants take precedence over inconsistent reference
listings or dimension formulas.

Related constructors are available at the compatible module paths:

```python
from symox.liealgebras.root_system import RootSystem
from symox.liealgebras.cartan_matrix import CartanMatrix
from symox.liealgebras.dynkin_diagram import DynkinDiagram

roots = RootSystem('A3')
assert roots.add_simple_roots(1, 2) == [1, 0, -1, 0]
assert len(roots.all_roots()) == 12
assert CartanMatrix('A3') == c.cartan_matrix()
```

`RootSystem` exposes simple/all roots, root addition, the Cartan matrix and a
text root-space description/Dynkin diagram. Adding two valid roots returns
their sum when it is a root, or the reference-style explanatory string otherwise.
The module does not supply arbitrary Lie brackets, structure constants,
representations, highest-weight modules, Weyl-group element calculations or
the reference's individual `type_a` through `type_g` class modules.

Tests compare Cartan matrices with SymPy and check root uniqueness, the expected
counts, integrality and closure under every simple reflection for all families,
including the 240 roots of `E8`. Tests also check the small-rank edge cases and
execute exceptional root construction with SymPy imports blocked.
